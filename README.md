# Confeitaria Bom A Car Bon 🍰

Sistema web de gerenciamento de uma confeitaria, desenvolvido com Python e Django.

## 🌐 Acesse o projeto

https://confeitaria-bom-a-car-bon.vercel.app/

## 🛠️ Tecnologias

- Python
- Django
- HTML e CSS
- PostgreSQL
- Neon
- Vercel

## ⚙️ Funcionalidades

- Cadastro e autenticação de usuários.
- Gerenciamento de produtos.
- Realização e acompanhamento de pedidos.
- Diferenciação entre clientes e funcionários.
- Painel administrativo.

## 👨‍💻 Projeto acadêmico

Desenvolvido como projeto de desenvolvimento web.
